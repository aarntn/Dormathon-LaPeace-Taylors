# App shell implementation plan

**Goal:** Deliver Prompt 1's reusable Figma components and an HTTPS `/components` review page; stop before Prompt 2.

**Spec:** User's Prompt 1 and repository-root AGENTS.md. The supplied Figma file remains the source of truth.

**Architecture:** React + Vite + TypeScript with Tailwind CSS, React Router and Framer Motion. Checked-in Figma token metadata generates CSS variables and Tailwind utilities. Small components use original local SVG exports. Route metadata drives one transition helper. The gallery fits a phone; a separate canvas review view uses the source frame's coordinates.

## Constraints and decisions

- Use all 22 colours from the Dormathon collection, plus the requested text styles and Heading/Display.
- Keep Figma names: Button `style`, IconButton `icon`/`theme`, TabBar `active`, Input `state`/`text`, Option `state`/`title`/`description`.
- BrandMark supports the component-set `theme` and the logo-set `version`; both use their original SVG exports and natural dimensions.
- Do not implement the Figma status bar, as requested. Leave its canvas slot empty in the comparison view and document this intentional difference.
- Native keyboard interaction, accessible control names and reduced motion remain supported.
- Use only the requested runtime dependencies and their normal TypeScript/Vite/Tailwind build tooling. No additional icon, font or testing dependency.
- Serve Inter locally, avoiding a network font dependency during review.
- HTTPS listens on the LAN using @vitejs/plugin-basic-ssl. Physical phone confirmation remains a user review checkpoint.

## Review focus

- Browser back must reverse push direction; push must not depend on current route's animation metadata during exit.
- Sheet close must reveal the retained underlying route and keep backdrop/focus behavior coherent.
- Gallery controls must actually toggle, edit and switch tabs; every variant must remain available.
- The app must fit 390 and 430 px viewports without horizontal overflow; AppFrame footer must account for safe areas.
- Fonts and vectors must load from local assets; self-signed development HTTPS may require certificate acceptance on the phone.
