# Car check implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan in the current session.

**Goal:** Build the seven Car check frames and stop at the visual review checkpoint.

**Architecture:** Seven routes reuse AppFrame, Button, IconButton and TabBar. C3 is a native modal dialog animated with the existing sheet transition; its rear-camera stream and captured image remain local. Report values are typed props with Figma defaults.

**Tech Stack:** Existing React, TypeScript, React Router, Framer Motion and Tailwind; no new dependencies.

**Spec:** AGENTS.md; apps/web/design/car-source.json; apps/web/design/car-prototype-links.json.

## Constraints

- Exact Figma copy, shared tokens and text utilities; original exported SVGs.
- No fake status bar. Phone safe areas and 34px footer offset.
- No uploads or real diagnosis in this UI phase.
- Build only Car check, then stop before Trips.

## Review focus

- Camera permission denial offers retry or skip; no shutter without a ready stream.
- Closing during a pending permission request stops any late-arriving stream.
- Capture and route changes stop all camera tracks and release local blob URLs.
- Direct routes and repeated back/close presses cannot reopen the dismissed camera.
- Short screens can scroll to all content above pinned footers.
